Какие проверки запускаются

Подсказчик выше помогает выбрать главное. Здесь можно открыть полный перечень и посмотреть, какие части программы проверяются отдельно.

Публичная публикация не подменяет закрытые проверки приложения

Ниже перечислены команды и область каждой проверки. Их закрытые журналы не выдаются за публичное доказательство. Публичная витрина проверяется локально перед ручным обновлением репозитория; удалённый CI не используется.

Техническая команда

Расчёт состава

Технические команды

Техническая команда
npm run test:fastБыстрый общий набор · локально и перед объединением
сборка

Публичная сборка

Проверяет статические страницы, запуск приложения, работу без сети и доступность.

Техническая команда
npm run public:smokeСборка и работа без сети · перед объединением

Как выбрать проверку: после изменения текста проверьте страницу, ссылки, изображения и её ширину на телефоне. После изменения расчёта или схемы запустите проверки именно этой части программы.
